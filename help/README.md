# Purely Music 帮助文档

本目录收录 Purely Music 的用户文档。应用内「设置 → 帮助」读取的是同一批文档的打包副本，位于 `app/src/main/assets/help/`，两份内容保持一致。

## 文档列表

### 使用说明.md — 快速上手指南

面向新用户，介绍导入音乐（单曲、批量、文件夹）、基本播放操作、创建播放列表、歌词显示与翻译、播放模式与音效设置、界面导航以及通知栏控制。

### 功能特性.md — 功能详解

完整介绍播放与控制、音乐库管理、界面设计、音频效果、歌词功能、播放列表管理、联网信息补全、系统集成与技术实现。

### 疑难解答.md — 常见问题

按导入、播放、歌词、翻译、音效、界面、性能等类别整理了常见问题与处理方式，包含文件夹导入的相关说明。

### 歌词翻译说明.md — 歌词翻译说明

说明歌词翻译的使用方法、API Key 配置、翻译效果与限制、故障排查及技术细节。

## 查看方式

- **应用内**：打开 Purely Music，进入「设置」页面，选择「帮助」，再选择需要查看的文档。
- **本地**：直接用任意 Markdown 阅读器打开本目录下的文件。
- **GitHub**：<https://github.com/XDXxc95/pure_music_pro/tree/main/help>
